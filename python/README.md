# 🚀 سكريبت SOSSKA1 لمسح عقود بينانس الآجلة وتنبيهات تيليجرام (sosska1_scanner.py)

سكريبت بايثون احترافي جاهز للإنتاج (Production-Ready) مبني لمسح أسواق العملات الرقمية مقابل USDT على منصة **Binance Futures (العقود الآجلة)** على فريم **15 دقيقة (15m)**، يقتنص فرص الاختراق والزخم اللحظي في الاتجاهين (**LONG صعوداً و SHORT هبوطاً**) مع نظام حماية ماكرو ومخاطر ديناميكية وإرسال تنبيهات فورية إلى Telegram Bot.

---

## 📌 المواصفات الرياضية وشروط القنص (استراتيجية SOSSKA1)

### 1. فلتر نظام السوق الكلي (Macro Market Regime)
- يفحص السكريبت أولاً زوج `BTC/USDT` على فريم **15 دقيقة** لتحديد وضع السوق العام قبل لمس أي عملة بديلة:
  * **سوق صاعد (BULLISH)**: إذا كان إغلاق BTC > `EMA(100)` -> يقتصر الماسح على صفقات **الشراء (LONG)** فقط.
  * **سوق هابط (BEARISH)**: إذا كان إغلاق BTC < `EMA(100)` -> يقتصر الماسح على صفقات **البيع (SHORT)** فقط.

### 2. شروط قنص الصفقات لكل عملة (15m Candle Close)

#### أ) سيناريو الشراء / الصعود (LONG) - يُفعّل فقط عندما يكون البيتكوين BULLISH:
1. **تقاطع صاعد حديث:** متوسط `EMA(5)` يقطع `EMA(15)` للأعلى.
2. **تأكيد الاتجاه العام:** سعر الإغلاق أعلى من خط الأساس `EMA(50)`.
3. **انفجار الفوليوم:** حجم الشمعة الحالية `>= 1.4 * SMA(Volume, 20)`.
4. **زخم صحي ومثالي:** مؤشر `RSI(14)` محصور بين **52 و 68** (قوة شرائية بدون تشبع مفرط).

#### ب) سيناريو البيع / الهبوط (SHORT) - يُفعّل فقط عندما يكون البيتكوين BEARISH:
1. **تقاطع هابط حديث:** متوسط `EMA(5)` يقطع `EMA(15)` للأسفل.
2. **تأكيد الاتجاه العام:** سعر الإغلاق أسفل خط الأساس `EMA(50)`.
3. **انفجار الفوليوم البيعي:** حجم الشمعة الحالية `>= 1.4 * SMA(Volume, 20)`.
4. **زخم بيعي قوي:** مؤشر `RSI(14)` محصور بين **32 و 48** (ضغط بيعي قوي بدون تشبع بيعي مفرط).

### 3. إدارة المخاطر وتحديد الأهداف (Dynamic ATR 14 Engine)
* **في حالة الشراء (LONG):**
  * وقف الخسارة (SL): `Entry - (1.8 * ATR)`
  * الهدف الأول (TP1): `Entry + (2.5 * ATR)` [عائد/مخاطرة 1 : 1.39]
  * الهدف الثاني (TP2): `Entry + (5.0 * ATR)` [عائد/مخاطرة 1 : 2.78]

* **في حالة البيع (SHORT):**
  * وقف الخسارة (SL): `Entry + (1.8 * ATR)`
  * الهدف الأول (TP1): `Entry - (2.5 * ATR)` [عائد/مخاطرة 1 : 1.39]
  * الهدف الثاني (TP2): `Entry - (5.0 * ATR)` [عائد/مخاطرة 1 : 2.78]

### 4. نظام منع التكرار وإدارة التيليجرام
* **نظام ذاكرة مؤقتة (Anti-Spam Cache):** يمنع تكرار إرسال تنبيه لنفس العملة في نفس الاتجاه إلا بعد مرور **90 دقيقة** على الأقل (محفوظ في ملف `sosska1_cache.json`).
* **معدل طلبات آمن (`enableRateLimit: True`):** ونوع الحساب `future` عبر مكتبة CCXT لمنع حظر الـ IP.
* **فحص دوري كل 15 دقيقة:** حلقة لا نهائية ذكية تترصد إغلاقات شمعة 15 دقيقة تلقائياً.

## 🛠 طريقة التثبيت والتشغيل السريع

### 1. المتطلبات الأساسية
- Python 3.9+ مثبت على جهازك أو السيرفر.
```bash
python3 -m venv venv
source venv/bin/activate  # في لينكس/ماك
# أو venv\Scripts\activate في ويندوز
pip install -r requirements.txt
```

### 2. إعداد مفاتيح التيليجرام في ملف `.env`
```bash
cp .env.example .env
```
افتح ملف `.env` واكتب:
```env
TELEGRAM_BOT_TOKEN="توكن_البوت_من_BotFather"
TELEGRAM_CHAT_ID="معرف_الدردشة_أو_القناة"
```

### 3. اختبار الاتصال بالتيليجرام
```bash
python sosska1_scanner.py --test-telegram
```

### 4. تشغيل فحص تجريبي (Dry Run)
```bash
python sosska1_scanner.py --once --dry-run
```

### 5. تشغيل السكريبت بشكل مستمر 24/7
```bash
python sosska1_scanner.py
```

## ⚙️ معلمات سطر الأوامر (CLI Flags)

| الأمر | الشرح |
| :--- | :--- |
| `--once` | تشغيل دورة فحص واحدة والخروج فوراً |
| `--dry-run` | محاكاة الفحص وطباعة التنبيهات في الطرفية دون إرسالها لتيليجرام |
| `--test-telegram` | إرسال رسالة اختبار فورية للتحقق من بيانات البوت |
| `--pairs BTC/USDT,ETH/USDT,SOL/USDT` | فحص أزواج محددة فقط |
| `--min-volume 5000000` | تخصيص الحد الأدنى لسيولة التداول اليومية (USDT) |
| `--interval 15` | تخصيص مدة الانتظار بين دورات الفحص بالدقائق |
